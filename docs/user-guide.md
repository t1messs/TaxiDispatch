# Посібник користувача TaxiDispatch

Для оператора диспетчерської, який бачить застосунок уперше. Номери сценаріїв (UC-01…) —
як у `docs/spec.md`.

## 1. Запуск

З кореня репозиторію: `dotnet run --project src/TaxiDispatch.App`. Після запуску видно версію
й головне меню:

```
TaxiDispatch v1.0.0 — диспетчерська служби таксі

1 — Прийняти замовлення (UC-01)
2 — Призначити водія (UC-02)
3 — Почати поїздку — пасажир сів (UC-03)
4 — Завершити поїздку (UC-03)
5 — Скасувати замовлення (UC-04)
6 — Знайти замовлення (UC-05)
7 — Звіт «Поїздки за зміну» (UC-06)
8 — Довідник місць
0 — Вихід
Ваш вибір:
```

Введіть номер пункту й натисніть Enter. Місця задають кодом із довідника (пункт 8, коди
P01…P50) або координатами «широта; довгота», наприклад `50,45; 30,52`.

## 2. Прохідні сценарії

Нижче — фактичний вивід застосунку; після двокрапки — те, що ввів оператор.

### Прийняти замовлення (UC-01) з помилками вводу

```
Ваш вибір: 1
Телефон пасажира (+380…): 0501
  ! Телефон у форматі +380XXXXXXXXX, наприклад +380501234567.
Телефон пасажира (+380…): +380936758699
  Пасажир: Сергій Дячук
Звідки (код P01…P50 або «широта; довгота»): P99
  ! Місце «P99» не знайдено: введіть код (P01…P50) або «50,45; 30,52».
Звідки (код P01…P50 або «широта; довгота»): P01
Куди: P03
Клас авто (1 — Economy, 2 — Comfort, 3 — Business): 5
  ! Клас авто: 1 — Economy, 2 — Comfort, 3 — Business.
Клас авто (1 — Economy, 2 — Comfort, 3 — Business): 1
  Прийнято замовлення № 121: Центральний залізничний вокзал → Майдан Незалежності,
  3,452 км, орієнтовно 112,50 грн
```

Замовлення прийнято о 22:51, тож оцінка — мінімальна вартість економу 90 грн × нічна
надбавка 1,25. Якщо телефону немає в довіднику, застосунок попросить ім'я й зареєструє
нового пасажира.

### Призначити водія й виконати поїздку (UC-02, UC-03)

```
Ваш вибір: 2
Номер замовлення: 121
  Призначено водія № 22 Микола Клименко, Toyota Yaris AA6915TO; до подачі 2,561 км
Ваш вибір: 3
Номер замовлення: 121
  Поїздка № 121 почалася о 17.11.2026 22:51
Ваш вибір: 4
Номер замовлення: 121
Фактичний пробіг, км (Enter — як довжина маршруту): дванадцять
  ! Пробіг — число більше 0 і не більше 500 км.
Фактичний пробіг, км (Enter — як довжина маршруту):
  Поїздку № 121 завершено: 3,452 км, до сплати 112,50 грн
```

Порожній ввід пробігу означає «як довжина маршруту». Після завершення водій стає вільним у
точці призначення.

### Заборонена дія (UC-04)

```
Ваш вибір: 5
Номер замовлення: 121
Причина скасування: пасажир передумав
  Відхилено: Дію Cancel заборонено для замовлення в стані Completed
```

Скасувати можна лише замовлення в станах New і Assigned. Застосунок не падає: оператор
бачить причину й повертається до меню.

Телефон пасажира: +380936758699
  Знайдено: 4
  № 6    14.11.2026 11:14  P18 → P29  Comfort  Completed  337,27 грн

## 3. Повідомлення про помилки

| Повідомлення | Що означає | Що робити |
|---|---|---|
| `! Телефон у форматі +380XXXXXXXXX…` | телефон не українського мобільного формату | ввести 13 символів: +380 і 9 цифр |
| `! Місце «…» не знайдено…` | коду немає в довіднику або координати поза межами | переглянути пункт 8 меню або ввести «широта; довгота» |
| `! Клас авто: 1 — Economy…` | невідомий клас | ввести 1, 2, 3 або назву класу |
| `! Номер замовлення — ціле додатне число.` | у номері є літери чи знак | ввести номер із UC-01 чи UC-05 |
| `! Пробіг — число більше 0 і не більше 500 км.` | пробіг нульовий, від'ємний чи нечисловий | ввести число, наприклад `12,5`, або Enter |
| `Відхилено: Замовлення № … не знайдено.` | такого номера немає | знайти замовлення через пункт 6 |
| `Відхилено: Немає вільного водія класу …` | у радіусі 5 км немає вільного водія потрібного класу | повторити призначення пізніше; замовлення лишається новим |
| `Відхилено: Подача й призначення ближчі за 0,5 км…` | поїздка закоротка | уточнити адресу призначення |
| `Відхилено: Дію … заборонено для замовлення в стані …` | дія не дозволена таблицею станів | перевірити стан замовлення через пункт 6 |
| `Дані пошкоджено: Файл …` | файл у `data/` чи `state/` має помилку | відновити файл із резервної копії (розділ 4) |

## 4. Де лежать дані й журнал

- `data/` — умовні дані з репозиторію; застосунок їх лише читає.
- `state/` — робочий стан: замовлення, водії й пасажири після змін. Створюється під час
  першого збереження. **Резервна копія** — скопіювати теку `state/`; щоб почати з умовних
  даних, видалити `state/`.
- `logs/taxidispatch.log` — журнал: час, рівень, номер сценарію, повідомлення. Телефонів та
  імен у журналі немає.

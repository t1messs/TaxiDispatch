# Реєстр дефектів проєктування: TaxiDispatch.Legacy

Файл: `TaxiDispatch.Legacy/LegacyRideProcessor.cs` (162 рядки, 149 значущих).
Номери рядків — за комітом «chore: додано успадкований модуль до рішення».

Порядок — за пріоритетом усунення: першими стоять дефекти, які найбільше заважають
подальшим крокам (поки метод довгий і вкладений, його не можна безпечно ділити, а поки
розрахунок дубльовано, будь-яку правку треба робити двічі).

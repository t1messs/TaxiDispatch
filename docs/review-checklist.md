# Чекліст огляду коду TaxiDispatch

Стандарт кодування 2.0.0, розділ 7.1. У чеклісті лише те, чого не бачить машина:
форматування, `using`, регістр імен, XML-документацію публічних членів, заборонені API і
складність понад 12 перевіряють збірка, `dotnet format` і `tools/check-standard.sh`.

Кожне зауваження — до коду, а не до автора, і з конкретною дією та номером правила:
«винесіть `0.9m` у константу `RegularRate` (D-05)», а не «незрозуміло».

- [ ] **R-02.** Одна сутність — одне ім’я: немає `Client` чи `Rider` замість `Passenger` (N-18).

# TaxiDispatch

Навчальний проєкт з дисципліни «Конструювання програмного забезпечення». 
Варіант № 13: приймання й розподіл замовлень таксі.

## Склад рішення
- `TaxiDispatch.Core` — логіка предметної області (бібліотека класів).
- `TaxiDispatch.App` — консольний застосунок (введення, виведення).

## Вимоги
.NET SDK 10.0 або новіший, Git.

## Складання та запуск
```bash
dotnet build
dotnet run --project TaxiDispatch.App
```

## Стандарт кодування
Правила описано у файлі CODING_STANDARD.md і закріплено в .editorconfig.
Перевірка: dotnet format --verify-no-changes
